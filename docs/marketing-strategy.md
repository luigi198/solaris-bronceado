# Solaris Bronceado — Digital Marketing Strategy

**Goal:** Maximize client acquisition through the website (`solarisbronceado.com`).  
**Scope:** No content creation. Acquisition channels, technical improvements, and conversion optimization only.  
**Market:** Local — San José, Costa Rica. Target: women 18–45 interested in beauty, wellness, and aesthetics.

### 1.2 Search Engine Indexing

The site must be discoverable before anything else can work. A site that isn't indexed gets zero organic traffic regardless of SEO quality.

**Actions:**
- [x ] Verify the site is not accidentally blocking crawlers — check `next.config.ts` has no `X-Robots-Tag: noindex` header and that `metadata.robots` in `layout.tsx` stays `{ index: true, follow: true }`.
- [x ] Generate a `sitemap.xml` by installing `next-sitemap` (`npm i next-sitemap`) and adding a `next-sitemap.config.js` at the repo root. This makes every URL discoverable to crawlers automatically.
- [x ] Create a `robots.txt` (also auto-generated by `next-sitemap`) that allows all crawlers and points to the sitemap URL.
- [x ] Register the site in **Google Search Console** — verify ownership via the HTML tag method (add a `<meta name="google-site-verification" ...>` to the root layout's metadata).
- [x ] Submit the sitemap URL (`https://solarisbronceado.com/sitemap.xml`) in Search Console under *Sitemaps*.
- [x ] Use the **URL Inspection tool** in Search Console to manually request indexing of the homepage. Google will crawl and index it within 1–3 days.
- [x ] Register on **Bing Webmaster Tools** and submit the same sitemap — Bing has a non-trivial share of searches in Costa Rica through mobile devices.

**KPI:** "Coverage" report in Search Console showing all pages as "Indexed". Should show 1 valid indexed URL within a week of submission.

## Phase 2 — Conversion Rate Optimization (CRO)

Getting traffic means nothing if visitors don't convert. These are changes to the website itself.

### 2.1 Booking Friction Reduction

The current CTA funnels to WhatsApp — good. But the path needs to be shorter.

**Actions:**
- [ x] Make the hero CTA button visible **above the fold on mobile** with no scroll required. Check on 375px width.
- [ x] Add a second sticky CTA bar at the bottom of the mobile screen (fixed, above the WhatsApp float) with "Reservar ahora" that links to WhatsApp. This mirrors what booking apps do and captures visitors who scroll without committing.
- [ x] The WhatsApp pre-filled message currently says "quiero información sobre bronceado" — change it to something more appointment-ready: `"Hola, quiero reservar una cita"`. Visitors who say "I want to book" convert at 3× the rate of those asking for "information".
- [ x] Add the phone number as a tappable link in at least 3 places: Navbar, Hero, Footer. On mobile, a tap-to-call is still a high-intent conversion.

### 2.2 Trust Signals

- [ ] Add a "real reviews" section that pulls from Google Reviews — even a manually curated static block of 3–5 recent Google reviews with the reviewer's name and star rating increases conversion. The existing `Testimonials` component is a good foundation; add the Google star rating graphic and a link to the full GBP listing.
- [ ] Add a **trust badge bar** below the hero: "X clientes atendidos · Productos certificados · Resultados desde la primera sesión". Quantified claims outperform generic claims.
- [ ] Add the mall logo/name ("Mall San Pedro") prominently. Physical presence in a known mall is a major trust signal for Costa Rican consumers.

### 2.3 On-Page SEO (Technical)

These changes make the existing pages rank better without writing new content.

- [ ] **Generate a sitemap** — install `next-sitemap` and configure it. Currently there is no `/sitemap.xml`. Google cannot efficiently crawl the site without it.
- [ ] **Fix the hours mismatch** — `layout.tsx` JSON-LD says Mon–Fri 9–7, Sat 9–5. The business is open every day 10am–8pm. Fix the structured data to match reality.
- [ ] **Add `streetAddress` to the PostalAddress** in the JSON-LD — "Mall San Pedro, Segundo Piso" should be in `streetAddress`, and `postalCode` added if known. Google uses this for local pack rankings.
- [ ] **Add `geo` coordinates** to the JSON-LD (`"@type": "GeoCoordinates", "latitude": ..., "longitude": ...`) — this directly helps Google Maps placement.
- [ ] **Add `aggregateRating`** to the BeautySalon JSON-LD once you have Google Reviews (e.g., `"ratingValue": "4.9", "reviewCount": "47"`). This shows stars in search results.
- [ ] **Image alt text audit** — run through all images in the public folder and ensure they have descriptive Spanish-language alt text that includes keywords like "bronceado brasileño Costa Rica".
- [ ] **Page speed** — run Lighthouse on the deployed URL. Aim for 90+ Performance score on mobile. Compress any hero images above 200 KB using WebP.

## Phase 3 — Paid Acquisition: Google Ads Local Campaign

Once GA4 is tracking conversions, launch a tightly scoped Google Ads campaign.

### 3.1 Campaign Type: Local Services Ads (LSA) + Search

**Local Services Ads** are the pay-per-lead format shown above regular search ads for local beauty services. They display a "Google Guaranteed" badge and are extremely effective for salons.

- [ ] Apply for Google Guaranteed verification in the beauty/wellness category.
- [ ] Once approved, set a budget of $5–10/day USD and let Google's algorithm optimize for calls and messages.

**Search Ads** (parallel, not instead of LSA):

- [ ] Create one campaign targeting: **San José, Costa Rica** only. No broader geo.
- [ ] Keyword groups:
  - **Brand:** "solaris bronceado", "solaris bronceado costa rica"
  - **Service intent:** "bronceado brasileño san josé", "spray tan costa rica", "bronceado sin sol san josé", "cama de bronceado san pedro"
  - **Competitor intent:** names of any competing salons (bid on their brand if legal in CR)
- [ ] Match types: broad match for discovery, exact match for brand. Add negatives: "cómo hacer bronceado en casa", "bronceado natural sol", "fake tan DIY".
- [ ] Ad copy: headline 1 = "Bronceado Profesional en San José", headline 2 = "Mall San Pedro · Desde ₡X", headline 3 = "Resultados desde la 1ra Sesión". CTA = "Reservar ahora".
- [ ] Landing: send all ad traffic directly to the homepage (it already has all sections). Do not create a separate landing page yet.
- [ ] Enable call extensions using `+506 8643-6657` and message extensions pointing to WhatsApp.

**KPI:** Cost per conversion (WhatsApp click or call), CPC, impression share. Target: under $3 USD per WhatsApp conversion.

## Phase 4 — Review Engine and Referral Loop

Reviews are free traffic multipliers. A salon with 50+ reviews outranks one with 5 reviews in Google Maps even if the latter has a better website.

### 4.1 Systematic Review Generation

- [ ] After each appointment, send a WhatsApp follow-up (manual or via WhatsApp Business) 24 hours later: "Hola [Nombre], ¿cómo te quedó el bronceado? Si quedaste satisfecha, nos ayudarías mucho con una reseña aquí: [GBP review link]". Keep the message short and personal.
- [ ] Create a shortened link (e.g., via bit.ly) to the Google review form — the direct GBP review URL — and save it in `src/lib/constants.ts` for use anywhere on the site.
- [ ] Add a **"Déjanos una reseña"** link in the Footer pointing to that Google review URL. It costs zero and compounds over time.
- [ ] Set a target: 5 new reviews per month minimum. Track monthly.

### 4.2 Referral Program

- [ ] Define a simple offer: "Trae a una amiga y ambas reciben 10% de descuento en su próxima sesión."
- [ ] Add this offer to the website as a small banner or section — a single sentence with a WhatsApp link pre-filled with "Hola, vengo referida por [nombre]". No software needed.
- [ ] Track referrals via the WhatsApp message prefix — ask every new customer "¿Cómo nos conociste?" and record it.
